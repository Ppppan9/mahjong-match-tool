# 麻将消除 · 广告玩法复刻工具

在线体验：https://ppppan9.github.io/mahjong-match-tool/

一个纯前端、**离线可用**的麻将消除（“Online Domino Cafe”广告同款玩法）网页工具：3D 麻将堆叠棋盘、配对消除、RELAX 目标字母收集、手指自动通关、自动录屏，以及覆盖全部游戏参数的控制面板。

## 打开方式
1. 解压后**直接双击 `index.html`**，用桌面版 Chrome / Edge（推荐 Chrome 126+）打开即可。
2. 不需要服务器、不需要联网：three.js 等所有代码都已内联在 `index.html` 里，不依赖任何 CDN（适合中国大陆网络）。

## 基本使用
- **手动游玩**：点击亮着的（未被压住的）牌。被压住的牌会变暗，不能点。
  - 视频模式：点一张牌会浮起，再点一张相同的牌，两张飞到一起爆出绿叶粒子消失。
  - 托盘模式：牌飞进右上角托盘，凑齐 2（或 3）张相同的自动消除。
  - 红色字母 R/E/L/A/X 点击后飞到托盘固定格（R→1 … X→5），集齐后托盘发光。
- **▶ 自动通关**：以缓动路径、随机抖动和“思考”停顿模拟真人点击节奏，每次点击出现黄色波纹，直到通关并显示结束页。默认**不显示手指**（没有内置手指图），上传手指图片后才显示。
- **⏺ 录制**：录制右侧画布的全部内容（棋盘、手指、波纹、粒子、托盘、Logo、结束页）。
  - 勾选“自动通关开始时自动录制”+“通关后自动停止并下载”，点一下自动通关即可得到完整视频。
  - 浏览器支持时输出 MP4（Chrome 126+），否则输出 WebM。分辨率可选 360×640 ~ 1080×1920，帧率 24/30/60，可调码率。
  - 录制完成会自动下载，同时在面板上方保留下载链接。
- **上传手指**：在“手指 / 自动通关”分组上传透明 PNG，然后在预览图上**点击指尖位置**设置锚点（也可用滑块微调大小、旋转、翻转、按压幅度）。上传后：自动通关时手指移动点击；手动游玩时（默认开启“手动游玩时手指跟随鼠标”）手指图片替代鼠标光标跟随移动。点“清除已上传手指”即恢复为无手指（只显示波纹）。旧版本保存的设置不会带回内置手指。
- **设置保存**：所有修改自动保存到浏览器 localStorage；可“导出设置”为 JSON、“导入设置”恢复，“恢复默认”一键还原。
- **🎲 换一局**：换随机种子生成新棋盘；**↻ 重新开始**：同一种子重开。

## 主要参数（控制面板分组）
- 棋盘布局：随机种子、堆叠层数、底层列/行数、每层递减、自定义各层网格（如 `7x8,6x7,5x6`）、每层横/纵向错位（默认半张牌）、错位交替、横/纵间隙、随机空位率
- 玩法规则：消除方式（视频模式/托盘模式）、托盘格数、几张相同消除（2/3）、目标单词、字母出现靠前程度、牌面种类数、各牌面集合开关、干扰字母集合
- 麻将外观：高宽比、厚度、绿色底座比例、圆角、牌面/侧边/底座颜色、图案大小、目标字母颜色（可逐个指定）、干扰字母颜色、阴影强度/偏移、被压住牌变暗程度
- 镜头：俯视倾角、视场角、棋盘缩放、上下偏移
- 场景/Logo/托盘：背景色（渐变两色）、背景图片、顶栏颜色/高度、托盘格颜色/大小、发光颜色、Logo 三行文字/丝带/图片/缩放、免责声明文字/字号/颜色、开场展示目标词及时长
- 动画/粒子：飞行时长、选中放大、爆开时长、粒子颜色×2、数量、大小、速度
- 手指/自动通关：速度倍率、移动耗时范围、点击间隔范围、思考停顿概率/时长、落点抖动、路径弯曲度、字母收集顺序、手指大小、指尖锚点 X/Y、旋转、翻转、上传手指图片、按压幅度、波纹颜色/大小/线宽/时长、手动时显示手指
- 录制：分辨率、帧率、格式、码率、自动录制、自动停止下载、通关后继续录制秒数
- 结束页：开关、出现延迟、标题、按钮文字、背景两色、按钮颜色、标题颜色、图标图片

## 关于“保证有解”
棋盘生成时从最上层开始“正向拆解”：每一步从当前未被压住的牌中随机选 2（或 3）张赋予相同牌面并移除，目标字母也在这一过程中放到当时可拿的位置。因此生成过程本身就是一条合法通关路线，棋盘必定有解。

## 二次开发
源码在 `src/`（`main.js` 主程序、`board.js` 生成与求解、`faces.js` 牌面绘制、`settings.js` 参数定义）。
修改后执行 `npm install && npm run build` 重新生成单文件 `index.html`；`npm test` 会用无头 Chrome 跑自动通关+录制测试。
