# 麻将消除 · 广告玩法复刻工具

在线体验：https://ppppan9.github.io/mahjong-match-tool/

一个纯前端、**离线可用**的麻将消除（“Online Domino Cafe”广告同款玩法）网页工具：3D 麻将堆叠棋盘、配对消除、RELAX 目标字母收集、手指自动通关、自动录屏，以及覆盖全部游戏参数的控制面板。

## 打开方式
1. 解压后**直接双击 `index.html`**，用桌面版 Chrome / Edge（推荐 Chrome 126+）打开即可。
2. 不需要服务器、不需要联网：three.js 等所有代码都已内联在 `index.html` 里，不依赖任何 CDN（适合中国大陆网络）。

## 基本使用
- **手动游玩**：点击亮着的（未被压住的）牌。被压住的牌会变暗，不能点。
  - 视频模式（默认，按参考视频逐帧复刻，见 `ref/ANALYSIS.md`）：点一张牌，它**原地变绿**；再点一张相同的牌，两张同时放大、**先向外侧飞出再弧线汇合**到中间并排，绿叶环绕散开后缩小消失。
  - 目标字母 R/E/L/A/X 也是**成对**出现的：配对消除后，字母飞进托盘对应格（R→1 … X→5）。不在单词里的字母（如红色 T）只是普通牌。
  - **集齐 RELAX 即通关**（与视频一致，棋盘不必清空）；可在“玩法规则 → 通关条件”改为“清空棋盘”，或把“目标字母规则”改为单张点击直接入托盘。
  - 托盘模式：牌飞进右上角托盘，凑齐 2（或 3）张相同的自动消除（此模式下字母为单张）。
  - 开场：棋盘压暗，RELAX 逐个弹进托盘，停留后淡出，再开始游戏。
- **▶ 自动通关**：以缓动路径、随机抖动和“思考”停顿模拟真人点击节奏，每次点击出现黄色波纹；会优先消掉压住目标字母的牌，并按概率穿插无关配对，集齐单词后显示结束页。默认**不显示手指**（没有内置手指图），上传手指图片后才显示。
- **⏺ 录制**：录制右侧画布的全部内容（棋盘、手指、波纹、粒子、托盘、Logo、结束页）。
  - 勾选“自动通关开始时自动录制”+“通关后自动停止并下载”，点一下自动通关即可得到完整视频。
  - 浏览器支持时输出 MP4（Chrome 126+），否则输出 WebM。分辨率可选 360×640 ~ 1080×1920，帧率 24/30/60，可调码率。
  - 录制完成会自动下载，同时在面板上方保留下载链接。
- **上传手指**：在“手指 / 自动通关”分组上传透明 PNG，然后在预览图上**点击指尖位置**设置锚点（也可用滑块微调大小、旋转、翻转、按压幅度）。上传后：自动通关时手指移动点击；手动游玩时（默认开启“手动游玩时手指跟随鼠标”）手指图片替代鼠标光标跟随移动。点“清除已上传手指”即恢复为无手指（只显示波纹）。旧版本保存的设置不会带回内置手指。
- **设置保存**：所有修改自动保存到浏览器 localStorage；可“导出设置”为 JSON、“导入设置”恢复，“恢复默认”一键还原。
- **🎲 换一局**：换随机种子生成新棋盘；**↻ 重新开始**：同一种子重开。

## 主要参数（控制面板分组）

- 麻将外观：高宽比、厚度、绿色底座比例、圆角、牌面/侧边/底座颜色、图案大小、目标字母颜色（可逐个指定）、干扰字母颜色、阴影强度/横向/纵向偏移、选中/飞行绿色、被压住牌变暗程度
- 镜头：正交相机（默认开，纯俯视无透视）、2.5D 侧面露出（向右/向下，牌宽比例）、俯视倾角（默认 0）、视场角（仅透视相机）、棋盘缩放、上下偏移
- 场景/Logo/托盘：背景色（渐变两色）、背景图片、顶栏颜色/高度、托盘格颜色/大小、发光颜色、Logo 三行文字/丝带/图片/缩放、免责声明文字/字号/颜色、开场展示目标词（开始时间、时长、逐个出现间隔、棋盘压暗）

- 手指/自动通关：速度倍率、移动耗时范围、点击间隔范围、思考停顿概率/时长、落点抖动、路径弯曲度、字母收集顺序、穿插无关配对概率、手指大小、指尖锚点 X/Y、旋转、翻转、上传手指图片、按压幅度、波纹颜色/大小/线宽/时长、手动时显示手指

- 结束页：开关、出现延迟、标题、按钮文字、背景两色、按钮颜色、标题颜色、图标图片

## 关于“保证有解”
棋盘生成时从最上层开始“正向拆解”：每一步从当前未被压住的牌中随机选 2（或 3）张赋予相同牌面并移除，目标字母也在这一过程中放到当时可拿的位置。因此生成过程本身就是一条合法通关路线，棋盘必定有解。

## 与参考视频对比
`screenshots/compare_*.jpg` 为参考视频帧（左）与本工具渲染（右）在相同时刻的并排对比：初始棋盘、开场 RELAX、第一次点击、配对飞行、汇合爆开、字母进托盘、结束页。可用 `node test/compare.mjs` 重新生成。旧版本保存在浏览器里的设置若仍是旧默认值（如 22° 倾角）会自动升级为新默认值；手动导入的 JSON 原样采用。

## v5 更新：配对飞行与消除（按视频逐帧复核）

* 两张牌**不论在哪，都沿弧线飞到画面固定位置（默认画面中部 0.47 W / 0.588 H）并排汇合**：靠左的先冲向左侧屏幕边缘、靠右的冲向右边缘，再收进中间；匀速约 1.05 s，飞行中放大到约 1.6 倍（实测值），汇合后停留时只再轻微放大 4%，随后缩小消失；全程不旋转。
* 字母对同样先飞到中部爆开，消失的同时字母直接在托盘格里弹出。
* 新增“消除动画”参数：汇合点模式（画面固定位置 / 两牌中点）、汇合点 X/Y、弧线弯曲程度、飞行缓动、最大放大倍数、汇合停留放大、飞行旋转角度；字母飞入时长设为 0 即为视频的“直接弹出”。
* 旧版本保存的默认飞行参数会自动迁移到新默认值（设置版本 5），自定义值和导入的 JSON 保持不变。
* 对比图：`screenshots/compare_match_sequence.jpg`（`node test/match-seq.mjs` 生成）。

## v6 更新：居中堆叠（金字塔）

* 默认堆叠方式改为“居中金字塔”：每往上一层，每侧缩进 `insetX`/`insetY`（默认各 0.5 张牌，即每层少 1 列 1 行），且每层都以同一中心对齐；下层在四周对称地露出半张牌。
* “列/行数指”默认为**顶层**：顶层保持参考视频的 6×8 砖块布局，下层逐层变大（3 层 = 8×10 / 7×9 / 6×8，共 190 张）；改成“底层”则底层固定、上层逐层变小。
* 层间微调 `stackNudgeX/Y` 按中间层对称分配，整体重心不偏；奇数行砖块错位按 ±半值对称分配；可选“抵消 2.5D 侧面造成的层间偏移”（默认开），让各层牌面在屏幕上同心。
* 摄像机按所有层（含侧面/底座）的整体包围盒自动居中，`boardOffsetX` 默认改为 0。
* 牌数需调整奇偶时，居中模式从最底层露出边缘的正中删牌，顶层保持完整、左右对称。
* 旧版“单向错位”保留为 `stackMode: offset`；旧存档若自定义过错位/递减参数、或导入旧版 JSON，会自动沿用旧版方式（设置版本 6）。
* 检查脚本：`node test/stack-shot.mjs` 生成 `screenshots/stack_centered.jpg`、`stack_centered_5layers.jpg` 并输出左右边距。

## v7 更新：默认改回参考视频的同尺寸居中堆叠

* 复核参考 t=0.2s 帧：初始棋盘四周**看不到任何下层牌的边**，只有顶层 6×8 砖块和每张牌自身的白色侧面/绿色底座；砖块本身左右对称（720×1280 下左 54 px / 右 55 px，顶层牌面从 y≈305 到 1203）。
* 因此默认改为：居中堆叠 + 缩进 0（各层同尺寸、完全重叠，抵消 2.5D 层间偏移，下层只在上层牌被拿走后露出），顶层仍是 6×8 砖块。
* 取景按像素对齐参考：`boardScale 0.849`、`boardOffsetY 0.062`、`tileRatio 1.2`、`gapY 0.048`；本工具量得左 54 / 右 55 / 顶 303，牌面 y 304–1201（参考 305–1203）。
* 金字塔仍可用：把“每层每侧缩进”设为 0.5（或更大）即可；旧版单向错位仍在“堆叠方式”里。
* 设置版本 7：v6 默认值（缩进 0.5、boardScale 0.86 等）自动迁移到新默认，自定义值与导入的 JSON 保持不变。
