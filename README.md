# 麻将消除 · 广告玩法复刻工具

在线体验：https://ppppan9.github.io/mahjong-match-tool/

一个纯前端、**离线可用**的麻将消除（“Online Domino Cafe”广告同款玩法）网页工具：3D 麻将堆叠棋盘、配对消除、RELAX 目标字母收集、手指自动通关、自动录屏，以及覆盖全部游戏参数的控制面板。

## 打开方式
1. 解压后**直接双击 `index.html`**，用桌面版 Chrome / Edge（推荐 Chrome 126+）打开即可。
2. 不需要服务器、不需要联网：three.js 等所有代码都已内联在 `index.html` 里，不依赖任何 CDN（适合中国大陆网络）。

## 基本使用
- **手动游玩**：点击亮着的（未被压住的）牌。被压住的牌会变暗，不能点。
  - 视频模式（默认，按参考视频逐帧复刻，见 `ref/ANALYSIS.md`）：点一张牌，它**原地变绿**；再点一张相同的牌，两张同时放大、**先向外侧飞出再弧线汇合**到中间并排，绿叶环绕散开后缩小消失。
  - 目标字母 R/E/L/A/X 也是**成对**出现的：配对消除后，字母飞进托盘对应格（R→1 … X→5）。不在单词里的字母（如红色 T）只是普通牌。
  - **集齐 RELAX 即通关**（与视频一致，棋盘不必清空）；可在“玩法规则 → 通关条件”改为“清空棋盘”，或把“目标字母规则”改为单张点击直接入托盘。
  - 托盘模式：牌飞进右上角托盘，凑齐 2（或 3）张相同的自动消除（此模式下字母为单张）。
  - 开场：棋盘压暗，RELAX 逐个弹进托盘，停留后淡出，再开始游戏。
- **▶ 自动通关**：以缓动路径、随机抖动和“思考”停顿模拟真人点击节奏，每次点击出现黄色波纹；会优先消掉压住目标字母的牌，并按概率穿插无关配对，集齐单词后显示结束页。默认**不显示手指**（没有内置手指图），上传手指图片后才显示。
- **⏺ 录制**：录制右侧画布的全部内容（棋盘、手指、波纹、粒子、托盘、Logo、结束页）。
  - 勾选“自动通关开始时自动录制”+“通关后自动停止并下载”，点一下自动通关即可得到完整视频。
  - 浏览器支持时输出 MP4（Chrome 126+），否则输出 WebM。分辨率可选 360×640 ~ 1080×1920，帧率 24/30/60，可调码率。
  - 录制完成会自动下载，同时在面板上方保留下载链接。
- **上传手指**：在“手指 / 自动通关”分组上传透明 PNG，然后在预览图上**点击指尖位置**设置锚点（也可用滑块微调大小、旋转、翻转、按压幅度）。上传后：自动通关时手指移动点击；手动游玩时（默认开启“手动游玩时手指跟随鼠标”）手指图片替代鼠标光标跟随移动。点“清除已上传手指”即恢复为无手指（只显示波纹）。旧版本保存的设置不会带回内置手指。
- **设置保存**：所有修改自动保存到浏览器 localStorage；可“导出设置”为 JSON、“导入设置”恢复，“恢复默认”一键还原。
- **🎲 换一局**：换随机种子生成新棋盘；**↻ 重新开始**：同一种子重开。

## 关于“保证有解”
棋盘生成时从最上层开始“正向拆解”：每一步从当前未被压住的牌中随机选 2（或 3）张赋予相同牌面并移除，目标字母也在这一过程中放到当时可拿的位置。因此生成过程本身就是一条合法通关路线，棋盘必定有解。

## v12 新功能：导出 After Effects 工程（每张牌、每个动画都是独立图层）

**结论（调研见 `docs/AE_EXPORT_RESEARCH.md`）**：`.aep` 是未公开的二进制 RIFX 格式，`.aepx` 里的图层/关键帧也是十六进制二进制块，都无法可靠地直接生成；因此本工具导出一个**工程包 ZIP**，在 AE 里运行其中的 ExtendScript 脚本，由 AE 自己用官方脚本 API 建出完整工程，再另存为 `.aep`。

**用法**
1. 面板「导出 AE 工程」→ 点 **● 开始记录**，然后点“自动通关”或自己手动玩；结束后点 **■ 停止并导出**，浏览器会下载 `mahjong_ae_export_时间.zip`。
   也可以勾选“录制视频时同步记录”（默认开）：点“开始录制/自动通关自动录制”时同时记录，停止录制后自动导出 ZIP。
2. 完整解压 ZIP，打开 After Effects（CC 2018+）→ **文件 > 脚本 > 运行脚本文件…** → 选 `build_ae_project.jsx`。
3. 脚本新建项目并生成全部合成和图层，最后询问是否另存为 `.aep`（保存在脚本旁边）。打开“主合成_麻将消除”预览。

**ZIP 内容**：`build_ae_project.jsx`（ES3 语法，自带 JSON 解析，路径相对脚本自身）、`timeline.json`、`README_AE.md`（中文步骤）、`assets/`（每种牌面用真实 3D 渲染器单独渲染的 PNG，含侧面/底座；选中变绿版；阴影、压暗剪影、左侧接触阴影；飞行牌/字母、树叶 8 种颜色、波纹、接缝光、闪光、星星、背景、顶栏、Logo、5 个托盘格、免责声明、结束页 5 个部件、手指）、`audio/`（`mix.wav` 混合音轨 + `sfx_*.wav` 每种音效）。

**工程结构**：主合成从下到上 = 背景 → 第1层/第2层/第3层（每层一个预合成：阴影 → 每张牌 + 选中 + 压暗 → 接触阴影；每张牌出点 = 被消掉的帧，点击处有标记，每层一种标签色）→ 开场压暗 → 顶栏/Logo/托盘格 → 开场字母 → RELAX 发光 + 星星预合成 → 托盘字母、飞行牌（层级切换的处理：配对后牌在棋盘层出点结束，同一帧在棋盘之上新建“飞行牌”图层，按网页的绘制层级 z 排序）→ 碰撞接缝光（相加模式）、闪光 → 树叶（每次爆开一个预合成，每片叶子一层）→ 点击波纹 → 免责声明 → 结束页预合成 → 手指 → 混合音轨 + 逐事件音效预合成。主合成上有每次点击/飞行/碰撞/字母/集齐/结束页的标记。

**面板设置**：AE 帧率 24/25/30/60；合成尺寸（同画布 / 720×1280 / 1080×1920）；关键帧方式（精简：线性插值误差 <0.3px；或逐帧烘焙）；树叶（每次爆开一个预合成 / 直接放主合成 / 不导出）；棋盘按层分预合成；中文/英文命名；音频（混合 + 逐事件 / 仅混合 / 仅逐事件 / 无）；脚本跑完提示另存 .aep。

**校验（AE 不在 Linux 测试机上，脚本未在真实 AE 中运行过）**：
- `node test/ae-export.mjs`：虚拟时钟下完整自动通关 + 短手动游玩（同时测试视频录制联动）+ 变体设置三次导出；
- `node test/ae-mock.mjs <zip…>`：acorn 以 ecmaVersion 3 解析 jsx；删除 JSON/forEach/indexOf/trim 等 ES5+ 内置后，在模拟的 AE 对象模型里执行脚本，逐图层核对数量、叠放顺序、入出点、关键帧数量与插值类型、位置拆分维度、标记、标签色、混合模式、素材导入、保存 .aep；
- `node test/ae-composite.mjs`：只用 timeline.json + PNG 按 AE 图层语义重新合成，与网页记录时的真实帧逐像素对比，输出 `screenshots/ae_export_check.jpg`。

**已知近似**：碰撞屏幕抖动（默认关闭）不导出；手指按下时阴影收缩、波纹线宽变细、结束页小灯闪烁、RELAX 发光模糊强度脉动为近似；逐事件音效层没有总线压缩器；合成尺寸大于画布时素材会被放大。

示例：`samples/ae_export_sample.zip`（完整自动通关）、`samples/ae_export_manual.zip`（短手动游玩），不进 git。

## v5 更新：配对飞行与消除（按视频逐帧复核）

* 两张牌**不论在哪，都沿弧线飞到画面固定位置（默认画面中部 0.47 W / 0.588 H）并排汇合**：靠左的先冲向左侧屏幕边缘、靠右的冲向右边缘，再收进中间；匀速约 1.05 s，飞行中放大到约 1.6 倍（实测值），汇合后停留时只再轻微放大 4%，随后缩小消失；全程不旋转。

* 旧版“单向错位”保留为 `stackMode: offset`；旧存档若自定义过错位/递减参数、或导入旧版 JSON，会自动沿用旧版方式（设置版本 6）。

## v9 更新：修复实机画面 / 顶层严格居中 / 碰撞 / 音效

* **根因**：在线版的旧本地存档会残留旧版布局参数（单向错位 offset 模式、层微调、旧汇合点、旧阴影等），以前的迁移把“与旧默认不同”的值当作自定义保留，于是画面层层错开、顶层偏左。另外相机按含右下侧面的包围盒居中，顶层牌面本身偏左约 4.5 px。
* **迁移 v9**：从本地存档升级时布局/镜头/阴影/配对动画参数恢复新默认，旧存档备份到 `mahjongTool.settings.v1.backup`，页面顶部出现横幅，可“撤销，用回旧值”或“全部恢复默认”。导入的 JSON 不受影响。
* **居中**：新设置“水平居中依据”（默认：最高层牌面）。所有视口、DPR、层数下顶层左右边距相等（720 宽画布 58.84/58.84 px）。
