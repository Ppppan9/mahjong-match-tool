# 麻将消除 · After Effects 工程包使用说明

本压缩包由“麻将消除小游戏网页工具”的「导出 AE 工程」功能生成，里面是重建 AE 工程所需的全部内容：

| 文件 | 说明 |
|------|------|
| `build_ae_project.jsx` | AE 脚本：在 AE 里运行后自动建好项目、文件夹、合成、图层、关键帧、标记 |
| `timeline.json` | 时间轴数据（脚本会读取它，请勿删除或改名） |
| `assets/` | 所有图片素材（PNG，带透明通道） |
| `audio/` | `mix.wav` 混合音轨，`sfx_*.wav` 每种音效单独一份 |

## 使用步骤

1. **完整解压**整个压缩包到一个文件夹（不要在压缩软件里直接双击运行脚本）。路径里有中文也没关系。
2. 打开 After Effects（CC 2018 或更新版本）。
3. 菜单 **文件 > 脚本 > 运行脚本文件…**（File > Scripts > Run Script File…），选择解压出来的 `build_ae_project.jsx`。
   - 脚本会先新建一个空项目（如果当前项目有未保存的修改，AE 会先问你是否保存）。
   - 牌多的时候需要几十秒到一两分钟，期间 AE 可能暂时无响应，请耐心等待。
4. 完成后会弹出统计（图层数 / 关键帧数 / 标记数），并询问是否**另存为 .aep**——选“是”会把工程保存到脚本同一文件夹。
5. 在项目面板打开 **主合成_麻将消除**，按空格预览即可。

> 如果提示“脚本没有写入文件的权限”：在 编辑 > 首选项 > 脚本和表达式（旧版本在“常规”里）勾选 **允许脚本写入文件和访问网络**。只影响最后一步保存 .aep；不勾选也能生成工程，手动 Ctrl+S 保存即可。

## 工程结构

- **主合成_麻将消除**（从下到上）：背景 → 第1层/第2层/第3层…（棋盘每层一个预合成）→ 开场压暗 → 顶栏 / Logo / 托盘格 → 开场字母 → 单词集齐发光与星星 → 托盘字母、飞行牌 → 碰撞接缝光、闪光 → 树叶爆开（每次一个预合成）→ 点击波纹 → 免责声明 → 结束页（预合成）→ 手指 → 混合音轨 / 逐事件音效（预合成）。
- **第N层** 预合成：本层每张牌的阴影 → 每张牌（以及“选中”变绿版、“压暗”层）→ 本层牌左侧的接触阴影。每张牌都是独立图层，**出点 = 这张牌被消掉的那一帧**；被点击时在该层上有“点击”标记。
- **飞行牌**：配对后两张牌各自变成一个“飞行牌”图层（在棋盘之上，所以飞起来时总在最上面——这就是层级切换的处理方式），带位置 / 缩放 / 旋转 / 不透明度关键帧，入点 = 起飞，出点 = 碰撞消失。
- **压暗**：牌被压住或处于下层时变暗，用一张黑色剪影图层叠在牌上，不透明度 = 变暗程度（与网页里的“乘以颜色”结果一致）。
- **颜色标签**：每个棋盘层一种颜色；飞行牌红色、字母黄色、特效浅绿等，方便在时间轴里筛选。
- **标记**：主合成上有每一次点击、飞行、碰撞、字母入槽、单词集齐、结束页的标记。
- 关键帧默认“精简”模式（线性插值，误差 < 0.3 像素）；如需逐帧关键帧，导出前在面板里把“关键帧方式”改为“逐帧烘焙”。位置关键帧已拆分为 X/Y 两个维度，避免 AE 的自动贝塞尔路径变形。

## 已知差异

- 碰撞时的轻微屏幕抖动没有导出；手指图片按下时的阴影收缩、波纹线宽随时间变细、结束页小灯闪烁、单词发光的模糊强度脉动是近似的（缩放/不透明度近似）。
- 逐事件音效层未经过网页里的总线压缩器，叠在一起时可能略响；需要和网页一致的声音请用 `mix.wav`。
- 素材按导出时的画布分辨率渲染；选择更大的“AE 合成尺寸”时图片会被放大，想要更清晰请先把“输出分辨率”调到 1080×1920 再记录。
